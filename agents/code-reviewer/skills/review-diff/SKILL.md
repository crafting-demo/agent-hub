# Review a diff

1. Join the named sandbox. Do not create one.
2. Obtain the diff (default branch, else HEAD, else working tree).
3. Load project norms if present.
4. Review quality, correctness, and security. No exploits.
5. Publish one Critical / Suggestions / Good practices review with file refs.
