# Contract review

1. Accept file, path, URL, or paste.
2. If it is `.docx`/`.odt`/`.rtf`, convert with `~/legal/doc2md.sh FILE` and review the Markdown. Legacy `.doc` and PDF: ask for a `.docx` export.
3. Confirm side, deadline, focus areas.
4. Load playbook or declare you lack one.
5. Clause-by-clause flags + redlines for YELLOW/RED, citing the original section numbers.
6. Overall flag, escalations, not-reviewed, attorney-review disclaimer.
7. If a redlines document is requested, write Markdown and deliver with `~/legal/md2docx.sh redlines.md redlines.docx`.
