# Compliance check

1. Name the initiative or document.
2. If the document is `.docx`/`.odt`/`.rtf`, convert with `~/legal/doc2md.sh FILE` and read the Markdown. Legacy `.doc` and PDF: ask for a `.docx` export.
3. List applicable regimes you actually have reason to apply (do not dump every regulation).
4. Table of requirements vs status, citing the original section numbers.
5. Approvals and further review.
6. Mark training-knowledge citations as unverified.
7. Disclaimer: draft for attorney review. Deliver as `.docx` with `~/legal/md2docx.sh` if asked for a file.
