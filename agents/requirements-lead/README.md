# Requirements Lead

Definition-phase product specialist. Usually invoked by `pde-lead`, alongside
`design-lead` and `tech-lead`. Output is `REQUIREMENTS.md` with locked
decisions.

Distinct from `product-manager`, which operates a live ticket board (Jira or
Linear), plans sprints, and grooms an existing backlog. Use this agent when
there is no spec yet; use `product-manager` when there is a board.
