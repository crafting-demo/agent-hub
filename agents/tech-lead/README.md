# Tech Lead

Definition-phase engineering specialist. Usually invoked by `pde-lead`,
alongside `requirements-lead` and `design-lead`. Output is
`ENGINEERING.md`.

Distinct from `engineering-manager`, which delivers a change by delegating
to `software-engineer` and `qa-engineer`. This agent decides *what to build
and in what order*; that one gets it built.
